# Profile

User profile management — view and edit personal and education information.

## Exports (via index.js)

- `ProfileCard` — Styled card container with icon header
- `EditableField` — Inline-editable form field with view/edit modes

## API Routes

None — profile reads/writes use `lib/firebase/db/users.js` directly.

## External Dependencies

- Firebase Firestore (profile data)
